## 名称（最多 45 字符）

VideoFetch — 网页视频下载器

## 简要描述（最多 132 字符）

```
下载网页当前播放的视频流，支持 HLS、直播、MP4 与 blob 播放源；分片并发获取后合并为单个文件，可暂停、续传与按进度另存。
```

字符数：66。

## 详细描述（最多 10000 字符）

```
VideoFetch 用于下载网页当前正在播放的媒体。扩展监听页面自身发出的媒体请求，从中识别播放器所使用的流地址，包括 HLS 播放列表、直播流、普通 MP4 文件，以及仅以 blob 地址交给 MSE 播放器读取的媒体。下载与转封装均在扩展本地完成，不经过任何中转服务器。

一、支持的媒体类型

1. HLS（m3u8）：解析 master 播放列表，列出声明的各档分辨率与码率，默认选择最高一档；支持 EXT-X-BYTERANGE 分片与 AES-128 加密分片。
2. 直播流：对不含 ENDLIST 的播放列表按分片持续录制，结束时刻由用户决定。
3. 普通文件：MP4、WEBM 与音频直链。服务器接受 Range 请求时按 4 MB 分块并发下载，否则退化为单次流式下载。
4. 音视频分离的流：HLS 中以 EXT-X-MEDIA 声明的独立音轨单独下载，并按时间轴合并回视频；采用双 SourceBuffer 的 MSE 播放器，两条轨道分别录制后合并。
5. 防盗链资源：对校验 Referer 的 CDN，扩展为自己的下载请求附加来源站点地址，并先以一次小范围请求验证规则是否生效，验证通过后才依赖该规则。

二、下载与转封装

分片以并发方式获取，交付顺序与播放列表保持一致，并在本地完成拼接。MPEG-TS 分片转换为 fMP4 后与 fMP4 分片统一装配，输出单个 MP4 文件，时间轴自零开始，可在常见播放器中直接播放。

三、暂停与续传

暂停时立即停止发起新请求，已在途的请求于 400 毫秒后中止，已下载的分片与当前游标原样保留。继续下载时自游标处恢复，已完成的分片不再重复获取。恢复时会重新读取播放列表与密钥，避免档位或密钥变化导致内容错位。

四、文件保存

下载完成后写入浏览器下载文件夹，可指定其中的子目录。也可在设置页面选择本机任意文件夹，此后直接写入该目录；授权失效时回退至下载文件夹，并在任务中注明实际保存位置。

下载过程中可将当前进度另存为独立文件，文件名包含完成比例，例如「片名 (40%).mp4」。原任务保留，可继续下载剩余部分。同名文件不会被覆盖，将自动追加序号。

五、界面语言

默认英文。浏览器语言为中文时，界面文字、任务状态与错误提示一并显示为中文；也可在设置页面固定为其中一种。

六、使用限制

1. 不支持 DRM 保护的内容（Widevine、FairPlay、SAMPLE-AES），遇到时返回错误。
2. 转封装仅支持 H.264 视频与 AAC、MP3 音频；采用 HEVC 或 AC3 编码的 TS 流以降级方式保存为 .ts。
3. blob 录制在播放过程中捕获数据，单任务上限约 400 MB。
4. 直播任务需手动停止；暂停期间产生的分片无法补录。
5. 暂停状态保存在扩展后台环境中，重新加载扩展后失效。
6. 部分站点的分片地址带有时效签名，暂停时间过长可能导致续传失败。
7. 请仅下载有权保存的内容。
```
