## 名称（最多 45 字符）

```
VideoFetch — 网页视频下载器
```

## 简短描述（最多 132 字符）

```
下载网页正在播放的 HLS、直播和 MP4：八路并发，随时暂停继续，合并成一个完整文件。
```

字符数：42。

## 详细描述（最多 10000 字符）

```
VideoFetch 看的是页面自己发出的那些媒体请求，把播放器背后的流交给你：HLS 播放列表、直播、普通 MP4，以及只暴露 blob 地址的播放器。

下载这一环是多数扩展省掉的部分。VideoFetch 一次拉八个分片、按顺序拼好，合并成一个到处都能播的 MP4。音视频分开给的站点，会把音轨单独取回来再接上，不会下完发现没声音。

能处理什么
· HLS（m3u8）：读 master 播放列表，列出每一档清晰度，默认最高
· 直播：边播边录，什么时候停你说了算
· 普通 MP4、WEBM、音频：服务器支持就给 4MB 分块
· AES-128 加密分片：自动取 key 解密
· 独立音轨与双轨 MSE 播放器：声音会被合并回去
· 防盗链：自动补来源站 Referer，自检通过才算数

暂停、继续、保存
点暂停当场生效：不再发新请求，在途请求 400ms 后掐断，分片游标原地留着。继续时从游标接着下，不用从头再来。「保存」把已经下好的部分另存一份，文件名形如「片名 (40%).mp4」，任务不结束，还能接着下完。

文件存到哪
默认写进浏览器下载文件夹，可以指定子目录；也可以在设置页选任意一个文件夹，之后直接写到那里。全程只在本机处理，不上传任何东西。

界面语言
默认英文；浏览器是中文时，界面、任务标签和报错一起切成中文。也可以在设置里固定一种。

需要知道的
· 不支持 DRM（Widevine、FairPlay、SAMPLE-AES），会直接报错，不会假装成功
· HEVC 或 AC3 的 TS 流会降级保存成 .ts，转封装只认 H.264 + AAC/MP3
· blob 录制是边播边录，上限约 400MB
· 直播必须手动停；暂停直播意味着错过的那段补不回来
· 断点状态存在扩展后台，重新加载扩展就丢了
· 部分站点分片带一次性签名，暂停太久再继续可能失败
· 请只下载你有权保存的内容
```
